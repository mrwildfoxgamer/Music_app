# Music player

MSK Wild – Music Player
This site hosts a web-based music player app that lets users play audio directly in the browser. It looks like a progressive web app (PWA) prompting visitors to install it for a better offline experience. The interface shows a basic music player UI with controls for selecting and playing songs, displays playback time, and supports common audio formats (e.g., MP3, FLAC). The app appears to load a playlist and is designed for quick access to music playback without needing a separate native installation. rief description of what this project does and who it's for

## Usage/Examples

```git clone
git clone https://github.com/mrwildfoxgamer/Music_app.git
```

### To  add custom songs 
```
1. Go to music folder
2. for flac music add them to the flac folder for other formats you can add to songs
```
### update the playlist.json
```
node generate-playlist.js #for all other formats
node generate-playlist.js #for flac music
```
### For custom app icons
```
change the icons on the icons folder
```
